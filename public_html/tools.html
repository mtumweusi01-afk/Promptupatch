AI tool directory

Every tool below is one PromptuPatch will route a prompt to. Grouped by the job, not by hype.

Chat & Writing

Draft, brainstorm, answer, explain.

  • ChatGPT — General-purpose chat, fast and flexible.
  • Claude — Careful reasoning, long documents, coding help.
  • Gemini — Google-integrated chat with multimodal input.
  • Grok — Real-time X data, a looser tone, and fast answers on current events.
  • DeepSeek — Open-weight reasoning at a fraction of the cost.

Research & Search

Find sources, verify facts, dig deep.

  • Perplexity — Cited, up-to-date answers from the live web.
  • You.com — Search-first assistant with app integrations.

Image Generation

Turn words into pictures.

  • Midjourney — The gold standard for stylized, painterly images.
  • DALL·E — Image generation inside ChatGPT.
  • Adobe Firefly — Commercially-safe image generation, Photoshop-native.

Video Generation

Turn words into motion.

  • Runway — Text-to-video and pro video editing tools.
  • Pika — Fast, playful short-form video generation.
  • Sora — High-fidelity text-to-video generation.
  • HeyGen — Turn a script into an on-camera avatar video, no camera or actor needed.

Code

Write, debug, and ship software.

  • GitHub Copilot — In-editor pair programmer.
  • Cursor — AI-native code editor for whole-codebase changes.
  • Claude Code — Agentic coding from your terminal.

Audio & Music

Voices, songs, sound design.

  • Suno — Full songs with vocals from a text prompt.
  • ElevenLabs — Realistic voice generation and cloning.

Docs & Productivity

Slides, notes, docs, work.

  • Notion AI — AI woven into your notes and docs.
  • Gamma — Prompt-to-slide-deck in minutes.
