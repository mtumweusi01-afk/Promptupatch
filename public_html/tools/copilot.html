GitHub Copilot

GitHub · Code · In-editor pair programmer.

GitHub Copilot is an AI pair programmer that lives inside your code editor, suggesting completions and whole functions as you type.

It's built around the day-to-day flow of writing code, rather than a standalone chat interface.
