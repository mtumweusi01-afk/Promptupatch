## Keyword & content gaps

1. **"X vs Y" head-to-head comparison content — still the single biggest gap, now two
   cycles running.** A generic search for `"ChatGPT vs Claude vs Gemini" comparison
   blog post ranking 2026` returned 9+ actively-ranking articles from sites with no
   special authority (Towards AI, Improvado, YUV.AI, gurusup.com, IntuitionLabs,
   tech-insider.org, Artificial Corner, The AI Report, aiblewmymind.substack.com) —
   this is one of the most saturated-yet-still-rankable formats in the whole AI-tools
   space, and PromptuPatch has zero pages built for it. `blog/one-prompt-five-tools.html`
   is adjacent (ran one prompt through five tools) but isn't structured or titled
   for the actual search query. Suggest a dedicated `blog/chatgpt-vs-claude-vs-gemini.html`
   (or a `tools/compare/` page type) that funnels straight into `/generate` — this is
   the one content type where PromptuPatch's live-routing product is a genuine
   differentiator against static comparison blogs (see Competitor notes).
   Source: [Towards AI](https://pub.towardsai.net/chatgpt-vs-claude-vs-gemini-which-ai-is-actually-best-in-2026-59a50c70dcdb), [gurusup.com](https://gurusup.com/blog/claude-vs-chatgpt-vs-gemini), [The AI Report](https://www.theaireport.ai/articles/chatgpt-vs-claude-vs-gemini-2026).

2. **AI app-builder tools are a full missing category, not just missing pages.**
   PromptuPatch's Code category covers Copilot, Cursor, and Claude Code — all
   in-editor/CLI coding assistants — but has no page for the "describe an app,
   get a working app" builders (Lovable, Bolt.new, v0, Replit Agent, Windsurf),
   which is one of the fastest-growing 2026 AI verticals and a near-perfect fit
   for PromptuPatch's own pitch ("describe what you want, get routed to the tool
   that does it"). This is a bigger opportunity than one page — it's a 7th-category-adjacent
   gap. Recommend starting with one or two tool pages (Lovable and/or Bolt.new,
   whichever has a workable deep-link/prefill URL per the site's own linking
   standard) rather than the whole category at once.
   Source: [Not-Diamond/awesome-ai-model-routing](https://github.com/Not-Diamond/awesome-ai-model-routing) and general 2026 AI-tool roundups surfaced this category consistently alongside coding tools (e.g. [LogRocket's AI dev tool power rankings, July 2026](https://blog.logrocket.com/ai-dev-tool-power-rankings/)).

3. **AI avatar/talking-video generation is missing from the Video category.**
   `tools/runway.html`, `pika.html`, `sora.html` all cover text-to-video/motion
   generation, but none cover the "AI avatar reads my script" category (HeyGen,
   Synthesia-style tools), which is a distinct search intent from "text to video"
   and shows up as its own line item in most 2026 AI-tool roundups (e.g. Lindy's
   guide lists Synthesia alongside Perplexity, Jasper, Notion AI as a top-18 tool).
   Fits the existing Video category directly; would need one new tool page.
   Source: [Lindy's "18 Best AI Platforms in 2026"](https://www.lindy.ai/blog/ai-platforms).

4. **"Free AI tools" practical/comparison post — still open from last cycle.**
   `blog/free-credits-philosophy.html` is opinion/philosophy about PromptuPatch's
   own credit model, not a comparison of which tools have usable free tiers. A
   companion practical post targeting "which AI tools are actually free in 2026"
   would catch higher-intent traffic and link back to the philosophy post and to
   individual tool pages. No new evidence against this cycle's finding beyond
   last cycle's — carrying it forward since it's still unaddressed.

5. **Long-tail "best AI tool for [job]" question posts, modeled on what Futurepedia's
   category pages already win on.** Futurepedia structures 50+ category landing
   pages around exactly this pattern ("best AI writing tool for X", "AI image
   generators") rather than single-tool reviews. PromptuPatch could adapt this at
   blog-post scale (not full category pages) for jobs its own 20 tools already
   cover well — e.g. "best AI tool for summarizing long PDFs" (Claude/ChatGPT),
   "best AI tool for turning notes into a slide deck" (Gamma) — each one ending
   in a `/generate` CTA instead of a static recommendation. Lower priority than
   items 1-3 because it's incremental content-marketing volume rather than a
   structural gap.
   Source: [Futurepedia case study, directorygems.com](https://www.directorygems.com/case-study/futurepedia-io) — "50+ categories create targeted landing pages for broader queries."

## Technical fixes

- **`public_html/tools.html` has a stale title baked into its anti-flicker script.**
  The `<title>` tag (line 6) and OG/Twitter titles correctly say "20 AI Tools,
  Sorted by What They Actually Do," and the `CollectionPage` schema correctly
  lists `numberOfItems: 20` — but the inline `MutationObserver` script at line 35
  still has `var t="18 AI Tools, Sorted by What They Actually Do | PromptuPatch"`.
  That script exists specifically to force the document title back to `t` any time
  the SPA JS changes it — so for any crawler or browser that executes JS, the live
  rendered title reverts to the stale "18 AI Tools" string, contradicting the
  meta description, OG tags, and schema on the same page. This is the only page
  on the site where the `<title>` and the lock-script variable disagree (checked
  all 30 files in `tools/` + `blog/` plus the 11 root pages — every other page
  matches). Fix: update line 35's `var t=` string to match line 6.
- **No page on the site sets `og:image` or `twitter:image`.** `public_html/og-image.png`
  exists (uploaded 2026-07-11, 40KB) but is not referenced by any `<meta property="og:image">`
  or `<meta name="twitter:image">` tag anywhere — checked all 41 HTML files under
  `public_html/`, zero matches for `og:image`. Every page currently falls back to
  a platform-default (often blank or a favicon-sized) card when shared on X,
  Slack, Facebook, or Discord — directly relevant since the Social agent is now
  live-posting to X. Fix: add `og:image`/`twitter:image` pointing at
  `https://promptupatch.com/og-image.png` to the shared page template.
- **`tools/grok.html` and `tools/deepseek.html` are internally under-linked
  relative to sibling tool pages.** Both pages exist, are in the sitemap, and are
  linked from `index.html` and `tools.html` — so they are not orphaned — but no
  *other* tool page's "Alternatives in [category]" section links to them.
  `tools/chatgpt.html`, `tools/gemini.html`, and `tools/claude.html` all list each
  other as chat-category alternatives but don't list Grok or DeepSeek, even though
  `grok.html` itself links out to `/tools/chatgpt` and `/tools/gemini`, and
  `deepseek.html` links out to `/tools/chatgpt` and `/tools/claude` — so the link
  relationship is currently one-directional. Adding Grok/DeepSeek into the
  "Alternatives" list on `chatgpt.html`, `claude.html`, and `gemini.html` would
  give both new pages contextual internal links beyond the two nav-level pages,
  which is worth doing before they've built any external backlinks.
- **Stale "19 tools" / "nineteen tools" copy in two blog posts, now inaccurate at
  20 tools.** `blog/we-tested-deep-links.html` says "19 tools" in its `<title>`,
  meta description equivalents, both JSON-LD blocks (`BreadcrumbList` headline and
  `BlogPosting` headline), the anti-flicker title-lock script, and the H1/body copy
  ("Out of the nineteen tools currently in our directory..."). `blog/ai-tool-red-flags.html`
  also says "the directory has nineteen tools instead of ninety" in body copy. Both
  were accurate at 19 tools (pre-Grok/DeepSeek) but the site now lists 20 in
  `tools.html`'s own schema. Not urgent — these are stylistic/narrative references,
  not machine-readable metadata that Google penalizes — but worth a Content-agent
  pass to reword as "twenty" or genericize to "our directory" the next time either
  post is touched, since the specific number appears in the page `<title>` (a
  ranking-visible string) for `we-tested-deep-links.html`.
- **No broken internal links, no orphaned pages, no duplicate meta descriptions.**
  Cross-checked every file in `tools/` (20) and `blog/` (10) against `sitemap.xml`
  in both directions — every file has a matching `<url>` entry and vice versa.
  Diffed all 20 tool-page and 10 blog-post `<title>`/meta-description pairs —
  all unique, no template leakage. `robots.txt` correctly disallows `/checkout`
  and `/api/`, and explicitly allow-lists GPTBot/PerplexityBot/ClaudeBot/
  Google-Extended — no stale entries found.
- **Domain has zero backlink authority (Ahrefs `public-domain-rating-free`:
  promptupatch.com = DR 0).** Not a fixable "technical" item per se, but relevant
  context for prioritization: with DR 0 against DR 70+ competitors (see below),
  ranking for any head term (e.g. "AI tool finder," "chatgpt vs claude") is not
  realistic in the near term regardless of on-page quality. The keyword gaps above
  are prioritized with long-tail, lower-competition phrasing for this reason.

## Competitor notes

- **There's An AI For That (theresanaiforthat.com)** — Ahrefs DR 77. The dominant
  generic AI-tool directory (claims ~90M users per its own positioning found via
  search). It's a browse/tag-discovery model, not a router — you search or filter,
  it lists candidates, you leave to evaluate each yourself. It cannot replicate
  PromptuPatch's core mechanic (type a prompt, get one tool pre-filled with it),
  so differentiation should stay on that functional gap in copy ("we don't hand
  you a list of 50 tools to compare — we tell you the one that fits this prompt").
  Source: [DirectorySurf's TAAFT-alternatives list](https://github.com/DirectorySurf/awesome-theresanaiforthat-alternatives), [Similarweb competitor data](https://www.similarweb.com/website/theresanaiforthat.com/competitors/).
- **Futurepedia (futurepedia.io)** — Ahrefs DR 72. Also a directory, but more
  disciplined about category-landing-page SEO: ~500K monthly visitors via 50+
  category pages built around "best AI tool for [use case]" query patterns
  rather than single-tool reviews. This is the most directly copyable *structure*
  (not content) for PromptuPatch's own long-tail blog strategy (see gap #5 above)
  — worth studying the category-page pattern, not the tool coverage.
  Source: [directorygems.com Futurepedia case study](https://www.directorygems.com/case-study/futurepedia-io).
- **airouter.io ("Your LLM Sommelier")** — Ahrefs DR 9, by far the closest DR-tier
  and conceptually the closest competitor found (automatic model routing) — but
  it's developer/API infrastructure: you integrate their SDK, change two lines of
  code, and it picks a model server-side. It has no consumer-facing prompt box
  and doesn't deep-link anywhere. This is useful positioning ammunition:
  PromptuPatch is the only product found this cycle that's zero-setup,
  consumer-facing, *and* deep-links to the actual branded consumer app with the
  prompt pre-filled — the API-routing space (airouter.io, OpenRouter's Auto
  Router, Not Diamond) and the directory space (TAAFT, Futurepedia) are both
  adjacent but structurally different products. Confirms last cycle's finding
  that the "AI model router" keyword territory belongs to a different (developer)
  audience and shouldn't be chased in titles/copy.
  Source: [airouter.io](https://airouter.io/), [Not-Diamond/awesome-ai-model-routing](https://github.com/Not-Diamond/awesome-ai-model-routing).
- **Comparison-blog genre (not a single competitor, but a competitive pattern):**
  the "ChatGPT vs Claude vs Gemini" query is being won by mid-authority blogs
  with no special AI-tool-directory positioning (Towards AI, gurusup.com,
  Artificial Corner, The AI Report) — meaning DR alone isn't the blocker for this
  specific format the way it is for head terms. That's the evidence behind gap #1
  being ranked first this cycle.
