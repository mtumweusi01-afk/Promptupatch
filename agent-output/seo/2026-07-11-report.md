# SEO Report — 2026-07-11

Scope: keyword/content gap scan, light competitor scan, and a spot-check technical
audit (5-6 pages + sitemap/robots cross-check, not exhaustive). WebSearch only this
cycle — Ahrefs connector isn't authorized yet, so no real backlink/ranking-volume
data. Treat the gap list below as directional, not volume-verified.

## Keyword & content gaps

1. **Missing tool pages for the current "Big 6" chat models.** PromptuPatch's
   `tools/` covers ChatGPT, Claude, Gemini, Perplexity, You.com — but not **Grok**
   (xAI), **DeepSeek**, or **Meta AI (Llama 4)**, all of which show up
   consistently as top-tier 2026 chat models in current comparison coverage.
   These are exactly the kind of "tool X vs tool Y" and "is tool X good for
   Y" queries PromptuPatch's existing pages are built to catch — right now
   that traffic has nowhere to land on the site. Suggest 3 new tool pages:
   `tools/grok.html`, `tools/deepseek.html`, `tools/metaai.html`, matching the
   existing template. (Source: multiple 2026 model-comparison roundups, e.g.
   ["Grok vs ChatGPT vs Gemini vs Claude: 2026 Comparison"](https://albato.com/blog/publications/grok-chatgpt-gemini-claude-overview),
   ["Google Gemini vs ChatGPT vs Grok vs DeepSeek"](https://aithinkerlab.com/google-gemini-vs-chatgpt-vs-grok-vs-deepseek-the-complete-comparison/).)
2. **"X vs Y" comparison content is a proven format PromptuPatch hasn't used yet.**
   Every competing roundup found this cycle was structured as a head-to-head
   comparison (Grok vs ChatGPT vs Gemini vs Claude, etc.) rather than
   single-tool pages. PromptuPatch's blog has none of these. Suggest a blog
   post like "ChatGPT vs Claude vs Gemini vs Grok: which one actually fits
   your prompt" that funnels into the existing tool pages and `/generate` —
   this format also gives natural internal-linking opportunities to 4+ tool
   pages at once.
3. **No page targets "free AI tools" / "AI tools with free credits" queries**
   despite the site already having a blog post on the topic internally
   (`blog/free-credits-philosophy.html`) — that post is philosophical/opinion,
   not a comparison. A companion practical post ("Which AI tools actually have
   a usable free tier in 2026") would target higher-intent, more searched
   phrasing while linking back to the philosophy post.

## Competitor notes

- **There's An AI For That (theresanaiforthat.com)** is the dominant AI-tool
  discovery site — a massive general directory (10,000+ tools, thousands of
  task tags), not a routing product. It wins on sheer coverage and task-tag
  breadth; it cannot compete with PromptuPatch on the actual "type a prompt,
  get it pre-filled into the right tool" mechanic, since it's a directory, not
  a router. PromptuPatch's differentiation should stay narrow-and-functional
  (curated 19-22 tools, working deep-link, preview answer) rather than trying
  to out-scale a 10,000-tool directory — that positioning should show up in
  copy ("we don't list everything, we route you to the right thing").
- The **general AI-router space** (OpenRouter, Portkey, LiteLLM) is not a real
  competitor — those are developer API gateways for calling models
  programmatically, a different audience than PromptuPatch's plain-language,
  consumer-facing prompt box. Worth explicitly not chasing that keyword
  territory (e.g. don't title anything "AI model router" — it'll pull in
  developer traffic looking for an API product, which bounces immediately and
  won't click ads for a consumer tool).
