## ⚠ Before you upload — verify this first

Both new pages include a **"Route a prompt to it"** link to `/generate`,
matching every existing tool page. That link's actual behavior is controlled
by the compiled SPA bundle (`assets/index-BLFRjWRo.js`), which nobody in this
pipeline has the source for or has touched. **I do not know whether the
router already recognizes "Grok" and "DeepSeek" as routable targets, or only
the original 18.** If it doesn't yet, that link will look normal but silently
fail to route correctly for these two tools once someone clicks it.
Recommend: test `/generate` with a Grok-shaped and a DeepSeek-shaped prompt
against the live site (or wherever the SPA source actually lives) before
uploading these two pages — or upload them with that one link temporarily
pointed straight at grok.com / chat.deepseek.com instead of `/generate` until
routing support is confirmed.
