# Content drafts — 2026-07-15

Drafted from `agent-output/seo/2026-07-15-report.md`. Picked 3 items this cycle,
spanning both formats already in use (tool page, blog post) plus one new
content *shape* (comparison post) built entirely within the existing blog
template — no new page type, CSS, or JSON-LD schema was introduced.

## New pages

- `drafts/blog/chatgpt-vs-claude-vs-gemini.html` — addresses gap #1 (the
  "X vs Y" comparison content gap, flagged as the top item two cycles running).
  Built on the exact `blog/picking-the-right-tool.html` template
  (`BlogPosting`/`BreadcrumbList` JSON-LD, same `#pp-pre` CSS, same title-lock
  script). Content reuses only the descriptive framing already published on
  `tools/chatgpt.html`, `tools/claude.html`, and `tools/gemini.html` (no new
  claims about any tool, no invented benchmarks or scores) and closes with a
  `/generate` CTA per the SEO report's specific recommendation for this post.
  Added one extra `<h2>` ("The tools mentioned here") linking the three tool
  pages, alongside the standard "Keep reading" blog cross-links — this is the
  only structural addition beyond what existing posts do, and it's just
  another `<ul>` under an `<h2>`, the same pattern the template already uses
  twice on every tool page.

  **Why a comparison post and not a new `tools/compare/` page type:** the SEO
  report offered both options. A new URL pattern would mean a second template
  variant (different breadcrumb depth, no single `SoftwareApplication` schema
  to hang JSON-LD off, unclear category placement in `tools.html`) — real
  design/IA work outside a content-only cycle. Expressing it as a blog post
  cost nothing structurally: the blog template already supports long-form,
  multi-paragraph, multi-link content, and the SEO evidence (gap #1's sources)
  shows the ranking pages for this exact query are blog-format articles, not a
  dedicated comparison tool. If this format proves out, a `tools/compare/`
  page type is a reasonable Website-agent follow-up later — not blocking this
  post from shipping now.

- `drafts/blog/which-ai-tools-are-actually-free.html` — addresses gap #4
  (carried over from the 2026-07-11 report as the fastest-to-ship item, since
  `blog/free-credits-philosophy.html` already exists as a natural internal
  link). Deliberately has **no specific free-tier numbers** (no "N free
  messages/day," no credit counts for any third-party tool) since I can't
  verify current limits and they change often — guardrail against fabricated
  claims took priority over specificity. Framed by category (chat/writing,
  image/video, coding) instead, and links back to the philosophy post and to
  `/generate`.
